BADBAADO PHYSIOTHERAPY - ANDROID PROJECT

APK waxaa lagu dhisi karaa GitHub Actions (computer la'aan):
1. GitHub account samee ama gal (github.com).
2. Samee repository cusub oo magaca BadbaadoAndroid, public ama private.
3. ZIP-kan extract garee, kadib files-ka folderka BadbaadoAndroid ku upload garee repository-ga (folder-ka app, gradle files, .github iwm).
4. GitHub repo -> Actions -> Build Badbaado APK -> Run workflow.
5. Marka build-ku dhammaado, fur run-ka -> Artifacts -> Badbaado-Physiotherapy-APK, download ZIP.
6. ZIP extract, app-debug.apk ku rakib Android telefoonka.

Haddii workflow-ga push main ku bilaabmo, Actions tab-ka ka eeg. APK-kan waa debug build,
ma aha release signing rasmi ah oo Google Play loo diyaariyey.
